A simple survey form web application built with HTML and CSS.

## Description
This project is a survey form that collects user feedback about a platform. It includes various input types including text fields, email validation, number input, dropdown menus, radio buttons, checkboxes, and a textarea for comments.

## Technologies
- HTML5
- CSS3

## Features
- Text input fields with placeholders
- Email validation
- Number input with min/max constraints
- Dropdown select menus
- Radio buttons for single-choice questions
- Checkboxes for multiple-choice questions
- Textarea for open-ended responses
- Submit button for form submission
- Required field validation

## Installation & Usage
To view this project locally:

1. Clone the repository:
```bash
git clone https://github.com/vanessapopa/Survey-Form.git
```

2. Navigate to the project directory:
```bash
cd Survey-Form
```

3. Open `index.html` in your web browser
